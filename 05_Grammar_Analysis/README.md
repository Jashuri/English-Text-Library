# 05_Grammar_Analysis

Сюди занось граматичні конструкції, які зустрів у текстах.

Фокусуйся не на сухому правилі, а на тому, як конструкція працює в реальному реченні.

Корисні категорії:

- Tenses
- Conditionals
- Passive voice
- Modal verbs
- Relative clauses
- Articles
- Prepositions
- Gerund / infinitive
- Complex sentence structure
