# Latest Technology Trends - Unit Structure

Цей unit краще тримати окремо, тому що він містить не один текст, а повний блок завдань:

- vocabulary before reading;
- reading passages A-H;
- title matching;
- comprehension questions;
- sentence completion;
- true / false;
- language in use;
- term-definition matching.

## Workflow

1. Спочатку опрацюй [Vocabulary](../../../03_Vocabulary_Bank/latest-technology-trends_vocabulary.md).
2. Прочитай [Reading Text](../../../01_Texts_To_Read/Latest%20Technology%20Trends.md).
3. Виконай [Exercises](latest-technology-trends_exercises.md), не відкриваючи answer key.
4. Перевір себе через [Answer Key](../../../08_Review_And_Anki/Answer_Keys/Latest_Technology_Trends/latest-technology-trends_key.md).
5. Додай складні слова/фрази в Anki або weekly review.
