# English Text Library

Це робоча база для читання англійських текстів, збору слів, аналізу граматики, словосполучень і повторення.

## Робочий процес

1. Поклади новий текст у `01_Texts_To_Read`.
2. Після прочитання перенеси його в `02_Read_Texts_Archive`.
3. Нові слова занеси у `03_Vocabulary_Bank`.
4. Корисні словосполучення занеси у `04_Phrases_Collocations`.
5. Складні граматичні місця розбери у `05_Grammar_Analysis`.
6. Сильні речення для запам'ятовування збережи у `06_Sentence_Mining`.
7. Використай нові слова у власних реченнях або міні-текстах у `07_Writing_Practice`.
8. Матеріал для повторення або імпорту в Anki тримай у `08_Review_And_Anki`.
9. Довідники, списки тем, посилання та правила зберігай у `09_Resources`.
10. Копіюй готові шаблони з `10_Templates`.
11. Аудіо до текстів, shadowing і власні записи зберігай у `11_Audio_Listening`.

## Рекомендована назва файлів

Використовуй формат:

`YYYY-MM-DD__topic__source.md`

Приклад:

`2026-10-01__work-life-balance__bbc.md`
