# 11_Audio_Listening

Тут зберігаються аудіоматеріали до текстів.

## Як організовувати аудіо

Для кожного тексту використовуй однакову базову назву файлу:

`YYYY-MM-DD__topic__version.ext`

Приклад для тексту `Metaverse - Interconnected and Interactive`:

- `2026-10-01__metaverse-interconnected-and-interactive__full.mp3`
- `2026-10-01__metaverse-interconnected-and-interactive__slow.mp3`
- `2026-10-01__metaverse-interconnected-and-interactive__shadowing.mp3`
- `2026-10-01__metaverse-interconnected-and-interactive__my-recording.mp3`

## Папки

- `01_Full_Text_Audio` - повне озвучування тексту нормальною швидкістю.
- `02_Slow_Audio` - повільна версія для першого прослуховування.
- `03_Shadowing_Practice` - версії з паузами або зручні для повторення вголос.
- `04_Sentence_Clips` - короткі аудіофрагменти окремих речень.
- `05_Your_Recordings` - твої власні записи для порівняння з оригіналом.

## Рекомендований процес

1. Прочитай текст очима.
2. Прослухай `slow` версію, дивлячись у текст.
3. Прослухай `full` версію без зупинок.
4. Зроби shadowing: повторюй за диктором із мінімальною паузою.
5. Запиши себе і поклади файл у `05_Your_Recordings`.
6. Випиши складні речення в `06_Sentence_Mining`.
