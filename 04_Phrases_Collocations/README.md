# 04_Phrases_Collocations

Сюди занось сталі словосполучення, фразові дієслова, ідіоми, chunks і природні вирази.

Приклади:

- `make a decision`
- `take responsibility for`
- `be likely to`
- `come up with an idea`

Фрази часто корисніші за окремі слова, тому краще записувати слово разом із типовим контекстом.

## Audio

Аудіо словосполучень зберігай у:

`../11_Audio_Listening/07_Phrase_Audio`

Для фраз краще робити один аудіофайл на ціле словосполучення, а не окреме аудіо для кожного слова.

Назва файлу:

- lowercase;
- слова через дефіс;
- без апострофів;
- `.mp3` в кінці.

Приклади:

- `to-interact-with-one-another.mp3`
- `to-blur-the-lines-between-a-and-b.mp3`
- `in-the-coming-years.mp3`
